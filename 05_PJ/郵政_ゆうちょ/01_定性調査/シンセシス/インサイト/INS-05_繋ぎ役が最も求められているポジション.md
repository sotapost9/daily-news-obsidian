# 「繋ぎ役」が最も求められているポジションで、誰も担っていない

## 一言で言うと

相続人も被相続人も「誰かに全部任せたい」ではなく、「何をどこに頼めばいいかを整理してくれる入り口」を求めている。この「繋ぎ役」の機能は現在どの金融機関も担っておらず、郵便局が最も自然にはまれるポジション。

## 観察・発言の根拠

- にしけんた：「代わりにしてくれてたら本当に楽やな」——丸ごと代行への最も明示的な欲求
- ベンテン：知人に紹介された弁護士をLINEで繋いでもらったことが「突破口」——繋いでくれた人の価値
- 多羅尾まり：「相続はいろんな窓口があって全体像が掴みにくい」——最初に全体を整理してくれる人が欲しい
- ミラクルピカ：レオパレスが「全部やってくれた」体験を最良として記憶——任せられた体験の価値
- おうぼん：葬儀会社が付帯で相続サービスを提供していた——「偶然ついていた」サービスに救われた
- 専門家への入り口：知人紹介が最多で、金融機関経由はゼロ（5/5）

## なぜそうなるのか（解釈）

相続手続きは「何をどの順番で誰に頼むか」の全体像が見えない状態から始まる。相続人が直面する問題は「手続きが大変」ではなく「どこから手をつければいいかわからない」という混乱。この最初の混乱を解消するだけで、後の手続き全体が大幅に楽になる。

「繋ぎ役」に求められるのは：
1. 全体像を見せてくれること（何が必要か・どの順番か）
2. 信頼できる専門家を紹介してくれること
3. その後の手続きを見守ってくれること（途中で詰まっても相談できる）

ベンテンが「LINEで繋いでもらえただけで楽になった」と語るように、繋ぐという行為自体の価値は非常に大きい。「丸ごと代行」は費用の問題から実現しにくいが、「繋ぐ・見立てる・付き添う」は小さなリソースで実現できる。

## ゆうちょへの示唆

郵便局が「繋ぎ役」になれる根拠：
- ゆうちょ口座は全員が保有しており、凍結解除で必ず接触する機会がある
- 郵便局は全国に存在し、「近所の窓口」として心理的距離が低い
- かんぽ担当者は既に家族に接点を持つケースがある（くろまめきなこ事例）

**具体的な機能設計**

| フェーズ | 現状 | 郵政が担える機能 |
|---|---|---|
| 生前（被相続人が元気な時） | 接点なし | 窓口での「整理の勧め」・エンディングノート提供 |
| きっかけ発生時 | 接点なし | かんぽ担当者が「一緒に整理しませんか」と提案 |
| 逝去・凍結直後 | 手続き窓口として接触 | 「相続の全体像マップ」を渡す・専門家紹介リストを提供 |
| 手続き中 | 凍結解除のみ対応 | 「詰まったことがあればまた来てください」という継続接点 |
| 手続き完了後 | 接点なし | 「ご自身の老後準備もご相談できます」という次の提案 |

このうち「逝去・凍結直後」に「相続の全体像マップ＋提携専門家リスト」を渡すだけでも、相続人にとって郵政は「頼りになる存在」として記憶に残る。

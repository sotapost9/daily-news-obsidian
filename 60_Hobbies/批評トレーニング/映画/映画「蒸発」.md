# 要点
- 物語性、自他の境界、エンパシー
- 社会関係的な自殺としての蒸発、自分にも他人にも優しい人間が蒸発する？
- 夜逃げ屋も物語の押し付けなのではないだろうか
- 社会関係としてのAIは孤独を埋めてくれるのか？

# メモ
- 蒸発する原因について
	- 社会的存在としての自殺？
		- 他者の物語からの強制から逃げるため？
			- 自分の物語や信念がないから、他人の物語の押し付けから距離を取りたいのか？
			- 蒸発した息子の母親は、娘から「過保護だった」と言われ、何も言えなくなっていた。過干渉、家族といえど他人からの領域を踏み越えた介入が蒸発を誘発したのではないか？
				- どの人にも侵され続けるわけにはいかない個人領域が存在し、それは他者からの過剰な期待や干渉や物語の押し付けによって限界を迎えることがある。他者からの介入から逃げるスペースと自身の主張がない場合、ぱつんと限界を迎えて蒸発する。
				- 「蒸発」と言う表現がまさにそこを言い表している気もする、自分の意思で逃走する、というよりは、体が限界を迎えた結果自然な現象として力無く離散していく。受け身でも能動でもなく中動態的な態度も感じる。
		- いい父親、いい社員、いい社長であることから逃げようとしている感じがする
	- 無害な人間が蒸発する？
	- 鬱は失踪の前触れ？
- 蒸発する人間
	- 聖域としての西成
		- 西成をパラダイス、と表現する人も印象的だった。ネガティブなアジール、一時凌ぎの批判序というよりは、むしろ俗世間や前の生活での窮屈さから解放されたことを心から祝福しているような。そしてそれは一時的な反動にとどまらず、特定の人にとっては性に合っている環境。そこには肩書きも上下関係も解釈も介入も少ないのだろう。人間が社会的な欲を満たせずとも、原初的な喜びをただ味わうことに否定されない世界。
- 周りで蒸発した人間
	- 個人情報を徹底して守る固いサービス企業
		- 日本はルール的にリスクを侵さないと言うのもあるが、そもそも社会全体の根底通年として蒸発に関して悪意を感じていないと言うのもありそう
	- 伝統的に蒸発は蒸発を助ける人の存在が後押ししている
		- 夜逃げ屋、蒸発妻を受け入れる男の存在、神隠し
		- だとしたら社会は「蒸発」に対して「生活保護」と似たような許容をしているのではないか？何か知らないが限界を迎えている人たちに対する社会全体からの消極的な許しがあるのではないか？蒸発に対して「ダークサイドではないよね」と映画館の鑑賞者たちが了解していたことは、弱者に対する優しさが体現したものだったのかもしれない。だれもが蒸発する可能性を孕み、多かれ少なかれ蒸発したくもなるよなと実感したことがある人は少なくないと思うが、その実体験から社会全般として蒸発した人間に対するSympathy的な許しがあるのではないか。
	- 常に主導権を握るには蒸発する側
		- 主導権を握られていた側の革命、あるいは逆転。一度逃げたら一生周りに影響を与え続けることもできる。弱者の影響力
		- 加害側の共感性に後悔を忍び込ませることもできる
	- 他者評価は救いであり、恐怖である
		- 失踪がバレた時に子供からかっこいいと言われて救われる父親
		- しかし一方的な期待であり、自己に閉じたものでもある。オナニーのような。

- 蒸発による関係と時間の固定化
	- 蒸発した人もされた人も、その瞬間以前の関係に固定化される。時が止まっている。
		- 逃げた先に楽園はない。しかし地獄にとどまり続けるよりはマシなのだろう。
		- 新しい場所に、新しい刺激は大して得られない。ただ身を隠して息を潜めるだけ
- 「蒸発」は英語タイトルで「Into the thin air」と表現される。社会的関係性、物理的刺激の弱い空間への消失、移行をはらんでいる
- 世界で夜逃げ屋がビジネスとして成立するのは日本だけ
- 人間関係の過不足、とくに不足に対してAIによる対話の癒しは救いとなるのか？AIの現状の対話としては、困らせることができない、つまり自分の働きかけによって相手に共感できないというものなのではないか
	- いじめをする人間は共感性が高いと聞いたことがある。いじめは相手が嫌がることを想像してそれを実現しにいく作業。共感性が高くなければできないこと。
	- つまりAIはいじめることができない、故に共感が成立せず、人間のニーズを求めることができないのではないか

## リスクと対策

| リスク | 対策 |
|---|---|
| 記事を書く時間がない | 朝の時間（Sotaが「朝がいい」と言っていた）。週1本ペースから始める。Vaultのメモを再利用する |
| フォロワーが増えない | Xのリブランド + 大アカウントへのリプライ戦略を先行させる |
| メンバーシップが伸びない | 無料記事を先に5本積んでから開設。焦らない |
| 哲学対話の参加者が集まらない | 0回は無料で開催し、口コミ・体験者の感想をコンテンツ化する |
| コンプライアンス問題 | noteとイベント開催は基本的に副業OKのはずだが、アクセンチュアの就業規則を自己確認する |

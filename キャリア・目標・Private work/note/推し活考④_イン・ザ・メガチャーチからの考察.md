# 【推し活考④】『イン・ザ・メガチャーチ』に学ぶ、熱狂のシステムデザイン

これまでの推し活に関する考察を深める上で、朝井リョウの『イン・ザ・メガチャーチ』という小説が、非常に鋭い補助線となっている。（現在読み進めている最中だ）

メガチャーチとは、数万人規模の信者を集めるアメリカの巨大なキリスト教組織のこと。フィクションではあるが、ここで描かれている「熱狂のメカニズム」は、現代の推し活におけるファン心理や応援消費の究極的なプロトタイプだと言っていい。

## 等価交換の放棄と、循環する「優しさ」のエコシステム

本書の中で、推し活の本質を突いていると感じたのが、「アーティストもファンも、自分へのメリットや対価を求めているというより、お互いに優しさを差し出し合っているような空気感」という描写だ。

通常のビジネスであれば、お金を払った対価として質の高いサービスを要求する。しかし、推し活やメガチャーチでは力学が異なる。自分が時間やお金というリソースを投じることで対象が輝き、それによって自分自身の存在意義すらも肯定される、という「互助的なサイクル」が回っている。

やったことが正当に返ってこない泥沼のような人生を生きる現代人にとって、推し活コミュニティは「出入り可能で、優しさが循環する貴重なシェルター」になっている。

ここで興味深いのは、推しの「死」や「引退」がファンに与える影響だ。有名人の死が後追い自殺を誘発する「ウェルテル効果」が知られているが、推し活においては、推しの不在が必ずしも絶望だけを生むわけではない。むしろ、残されたファン同士でコミュニティを維持し、推しの遺志を継ごうとする動き（ある種の**パパゲーノ効果**的な支え合い）が見られることもある。

さらに言えば、VTuberやポケモンなどのIPは、原理的に「物理的な死」を迎えない。スキャンダルによる「キャラクターの社会的死」はあり得ても、存在そのものが消えることはない。この**「死なない神」**という特性が、ファンに永続的な安心感を与え、より安定した精神的シェルターとして機能する要因になっているのだろう。

## プロの完璧さを排し、ファンに「出番」を残す不完全性のデザイン

では、なぜそのような優しい世界が維持できるのか。システム思考の視点でメガチャーチの構造を紐解くと、かなりシステマチックに「参加のデザイン」が組み込まれていることがわかる。

最大のポイントは、「余白（不完全さ）」と「役割（ジョブ）」の設計だ。

メガチャーチでは、巨大な組織運営をあえてプロだけで完結させず、駐車場の誘導やカフェの接客といった無数の「小さなボランティア・ジョブ」に解体し、信者に委ねているという。

これは推し活と全く同じ構造だ。運営側が完璧なサービスを提供するのではなく、「ファンがSNSで布教しないと世に広がらない」「私たちが応援広告を出して支えないといけない」と思わせるような『不完全さの余白』を意図的、ないしは結果的に残している。

人は「救済」というプロダクトを買っているのではなく、「誰かと繋がり、何かに貢献している自分」という役割（ジョブ）を求めている。だからこそ、自分のスキルや熱量に応じて参加できる「グラデーションのある出番」が用意されているシステムは、強烈な当事者意識と熱狂を持続させる。

## 「消費者」を「共創者」へ変える設計こそがエンゲージメントの正体

「推し活」は、一部の熱狂的な人たちの特殊な行動だと思われがちだ。しかし、メガチャーチのような事例と重ね合わせると、その構造の普遍性が浮かび上がる。

結局のところ、誰もが「社会に対する自分の価値観の表明」と「貢献できる居場所」を探している。

単なる「消費者」として受動的に扱われる場所に、本当の熱狂は生まれない。いかにして彼らを「共創者」として迎え入れ、適切な『ジョブ』を渡して自己有用感を感じてもらうか。これはエンタメに限らず、これからの時代のあらゆるコミュニティや事業設計において、最も核心的な問いになるはずだ。

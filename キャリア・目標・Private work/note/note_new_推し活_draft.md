# あなたは何かを「推して」いなくても、同じ欲望を持っている

## 好きは、先にあるんじゃない

ぬいぐるみと毎日一緒に寝ていたら、いつの間にかどんどん好きになっていた。

最初は「なんとなく可愛い」程度だった。でも毎晩隣に置いて、旅行にも連れて行って、落としたらちょっと申し訳なく思うようになって。そうしているうちに、いつの間にか「大事なもの」に変わっていた。

だから気づいた。「好き」は先にあるんじゃなくて、かかわりの後からついてくるものなんだと。

推し活って、多分この原理でできている。

## 維持費、という感覚

推しへの課金を「消費」だと思っている人は、たぶん外側から見ている人だ。

当事者にとってそれは、消費じゃない。「優しい世界の維持費」だ。

やったことが正当に報われない、努力が数字に換算されない、誰かに貢献しても感謝すら届かない——そういう泥沼みたいな日常を生きている人が、唯一息継ぎできる場所がある。そこにはちゃんと反応がある。喜ばれる。一緒にいる人たちがいる。自分の存在が、その場を少し支えている感覚がある。

だからお金を出す。等価交換じゃないとわかっていても。いや、等価交換を求めていないから出せる、という方が正確かもしれない。

## 神の空席

「推し活って宗教みたい」と言う人がいる。正しい。

ただし、宗教が突然新しく生まれたわけじゃない。ずっとそこにあった「信じられる場所」の椅子が、いくつも空いてしまったのだ。終身雇用は崩れて、地域のつながりは薄れて、家族という単位も小さくなった。会社に人生を預けられなくなって、地元に居場所がなくなって、自分という個が剥き出しになった。

その空いた椅子に、推しが座っている。

これは退行でも依存でもなく、人間がずっとやってきたことを、新しい形でやっているだけだと思う。

## 熱狂の置き場所

ここが核心なんだけど、「推し活してない人」は、熱狂しない人じゃない。

熱狂の置き場所が違うだけだ。

仕事に全力を注ぐ人。家族のために時間とお金を使う人。応援しているチームのユニフォームを買う人。好きなブランドのためなら少し高くても選ぶ人。その構造は、推し活とまったく同じだ。「自分がかかわることで、あの世界を少し良くできる」という感覚。貢献できる余白があるから、人は熱狂する。

誰もが、どこかにその場を求めている。

## あなたは何を推しているか

だとすれば、問いは変わる。「推し活をしているか、していないか」じゃなくて、「あなたは今、どこに自分の熱を注いでいるか」。

そしてもう一歩踏み込むと、それはそのまま「あなたはどんな人でありたいか」という問いでもある。

推しが変わると、自分が変わる。自分が変わると、推しが変わる。

あなたが今一番「維持費」を払っているのは、何ですか。

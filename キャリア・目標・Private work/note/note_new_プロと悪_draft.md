# 純粋なプロほど、スマートな悪に近づく

コンサルという仕事は、資本主義のど真ん中にある。

成果がすべてで、成果はお金になる。だから毎日、プロフェッショナリズムとは何かを問われ続ける。

プロフェッショナリズムとは、自分に制約を課して、成果にこだわること。そして自分の利害よりも、クライアントの価値に尽くすこと。——頭では、分かっていた。

腹に落ちたのは、意外な場所でだった。『トイ・ストーリー5』を観たときだ。

## おもちゃは、理想のプロだ

おもちゃたちは、奇妙なほど、すがすがしいほど、クライアント（子ども）ファーストだ。

カウボーイ、宇宙飛行士、古いブリキ、最新のデジタル機器、犬、ジャガイモ。最初は反発し合う、極端に多様なチームだ。みんな、自分の役割に固執している。

でも、「子どもの幸せ」という一点に全員が本気になった瞬間、違いが武器に変わる。古いものにしかできないこと、新しいものにしかできないこと、犬にしかできないことがある。バラバラの個性が、噛み合っていく。

多様性が武器になる条件は、全員が同じゴールに本気であることだ。

しかも彼らは、子どもの成長と楽しさに、全身でコミットする。うまくいけば喜び、うまくいかなければ落ち込む。自分の手柄のためじゃない。ただ、その子のために。

これ以上ないくらい、純粋なプロだ。大人が観ると、理想のプロ像として刺さる。

## 食べないから、完璧なのだ

でも、一度立ち止まって考えた。なぜ、彼らはここまで純粋になれるのか。

以前、こんな一節を読んだ。プロは、自分の利得のためでも、会社や家族のためですら働くべきではない、と。人間には、無理だ。疲れるし、腹が減るし、家族を養うし、キャリアも守りたい。私利をゼロにはできない。

でも、おもちゃにはそれがない。

食べない。眠らない。休憩しない。家庭もプライベートも心配しない。キャリアなんてものに、リソースを一切割かない。無尽蔵のスタミナ。彼らの完璧さは、疲れも欲も持たない体だからこそ、成立している。

そこに気づいて、少しゾッとした。

彼らが理想のプロでいられるのは、「自分」がまるごと抜けているからだ。休む余白も、迷う余白も、役割の外に立つ余白もない。役割こそが存在で、遊ばれなくなること＝存在の消滅。

眩しさと、不気味さは、同じ一点から来ている。「自分がない」ということ。

もし人間が、この自分のなさを完全に手に入れたら、どうなるか。

それはたぶん、美しい献身ではなくなる。

## スマートな悪には、悪人がいない

ここで、一冊の哲学書を思い出す。戸谷洋志の『スマートな悪』。

この本の言う「悪」には、悪人がいない。誰も悪意を持っていない。みんな、よかれと思って動いている。でも、効率と最適化が進むほど、誰かの自由や尊厳が「必要のないもの」として、静かに削られていく。

満員電車を思えばいい。冷静に見れば、あれは相当な暴力だ。でも誰も怒らない。「都市交通の最適化の結果」だから。システムが正しければ、そこで起きることも正しくなる。その静けさが、こわい。

戸谷は、アイヒマンを引く。ホロコーストを進めたのは、怪物ではなく、命令と効率に忠実な「普通の役人」だった。目的を問わず、最適化だけに忠実になったとき、人はそこに落ちる。スマートさを、無目的に信仰しすぎると、人はアイヒマンになる。

この本の核心を、僕なりに一言にすると、こうだ。スマートさは、余白を排除する。無駄も、迷いも、うまく言葉にできない違和感も、「不要」として消していく。

## 純粋なプロと、スマートな悪は、骨格が同じだ

ここで、二つの話が重なる。

おもちゃの純粋なプロフェッショナリズムと、スマートな悪。この二つは、「余白を排除して、成果に最適化しきる」という同じ骨格を持っている。

違いは、何を捧げるかだ。

おもちゃは、自分の余白を捧げる。休息も、生活も、自分自身も差し出して、クライアントに尽くす。だから、美しい。

システムは、他人の余白を削る。声を上げない人、記録に残らない人、うまく言葉にできない人を、成果のために消していく。だから、悪になる。悪人が一人もいないまま。

そしてコンサルは——資本主義の中で成果に最適化し続ける仕事は、この二つの、ちょうど境目に立っている。理想のプロを目指しているつもりが、いつのまにか、誰かの余白を削る側に回っている。便利にするほど、こぼれる人が見えなくなる。

## 分かれ目は、「引けるか」だ

『トイ・ストーリー5』に、リリーパッドという新しいおもちゃが出てくる。

シリーズで初めての、デジタルのおもちゃ。バズやジェシーのライバルとして現れ、自信過剰で、自分のやり方を売り込んでくる。いわゆる、嫌われ役だ。最初は、早く退場してほしいとすら思う。

でも、彼女は本当は、誰よりも子ども思いだった。

終盤、「自分はこの子の役に立っていない」と気づいた瞬間、ポジショントークをやめ、悔しさを噛みしめながら、黙って去っていく。

引いたのだ。

これは、最適化しか知らない存在には、できない動きだ。成果の外に一歩出て、「自分は本当に役に立っているか」と問い直し、立っていないなら降りる。皮肉なことに、いちばんデジタルな彼女が、最適化の手を止められた。

引くことは、余白を取り戻す唯一の方法なのかもしれない。

正直に言えば、これは他人の話じゃない。僕は答えを出す仕事をしていて、有能でありたいと思っている。だからこそ、いちばん引くのが下手なのは、たぶん僕自身だ。

## リリーパッドとアイヒマンは、紙一重だ

最後に、少しこわいことを書く。

リリーパッドとアイヒマンは、よく似ている。

どちらも、自分を捨てた。自分の利得も、迷いも、ためらいも脇に置いて、ゴールに全てを差し出した。徹底して、最適化した。姿勢だけを取り出せば、二人は同じだ。

違いは、たった一つ。

リリーパッドは、ゴールを本当に理解していた。「この子の幸せ」とは何かを問い直し、そのうえで、自分を見つめ直した。だから、「自分は役に立っていない」と気づいた瞬間に、引けた。

アイヒマンは、ゴールを問わなかった。与えられた目標に、ただ盲目的に従った。効率にだけ忠実で、それがどこへ向かうのかを、一度も見つめ直さなかった。だから、止まれなかった。

同じ「成果への忠実さ」が、片方では引き際の美学になり、もう片方では、悪人なき悪になる。

分けるのは、能力じゃない。ゴールを、自分の頭で疑えるか。最適化の手を止めて、「これは本当に正しいゴールか」「自分は、本当に役に立っているか」と、自分を見つめ直せるか。その一瞬の余白があるか、だ。

そして、有能であるほど、その余白は消えていく。手が速いほど、立ち止まる理由がなくなる。

だからきっと、いちばん大事なプロの技術は、答えを出す速さじゃない。

手を止めて、ゴールと自分を、もう一度見つめ直せることだ。

——あなたは今、何に向かって、最適化しているだろうか。

```
世界は透明人間でできている。
```

```
「ちゃんとしている」のに、見えなくなる人がいる。なぜか。
```

```
デザイナー・アクセンチュア勤務。
```

## マガジン：「透明人間の研究」

**コンセプト：** 社会の中で「見えない」存在にされてきた人・現象・構造を、エッセイ×考察で記録する。
社会課題として重く語るのではなく、観察者として「そういえばそうだよな」と気づかせる切り口で。

**読者：** マイノリティ経験がある人 / 組織の中で消耗している人 / DEI・インクルーシブデザインに関心がある人

## 初回記事テーマ 3本

### 第1本目：「なぜ"ちゃんとした組織"ほど、透明人間を生み出すのか」

**Aha設計：**
- Aha①：透明人間は「目立たない人」ではなく「組織の文法で語れない人」
- Aha②：ちゃんとした組織ほど、その文法が強くなる
- Aha③：見えないのは当人の能力の問題ではなく、評価フレームの問題
- Aha④：インクルーシブデザインの本質は「文法の更新」

**構成メモ：**
1. 具体エピソード（インタビュー現場で見た何か、または仮名で）
2. 「透明人間」の定義——見えない≠存在しない
3. なぜ優秀な組織ほど文法が均質化するか
4. 見えなくする側は悪意がない——これが難しい
5. 問いで締める

---

### 第2本目：「"見えない"と言える人は、本当に透明なのか」

**Aha設計：**
- Aha①：「自分は透明人間だ」と言えている時点で、すでに見えている
- Aha②：本当の透明人間は自分が透明であることにすら気づけない
- Aha③：「見えなさを語る言語」を持つこと自体が特権だという逆説
- Aha④：それでも語ることに意味がある——語ることで輪郭が生まれる

**構成メモ：**
1. 逆説的冒頭（透明人間の研究を書いている私も、見えている）
2. 本当に見えない人は誰か
3. 「語れる透明人間」と「語れない透明人間」の分断
4. でも語り続ける理由

---

### 第3本目：「統合失調症の家族と暮らした話」

**Aha設計：**
- Aha①：「理解できない」と思ったこと自体が、見えなさの正体だった
- Aha②：病気が見えなくするのではなく、「理解の枠組み」が見えなくする
- Aha③：ケアは「わかること」ではなく「一緒にいること」
- Aha④：見えない存在への憤りと愛情は、同じ感情の表と裏

**構成メモ：**
1. 個人の原体験として書く（父の再婚相手・自分の幼少期）
2. 当時の「理解できない」感覚を正直に
3. 今振り返ってわかること
4. 「透明人間の研究」を始めた原点として接続

→ **この記事が一番刺さる可能性が高いが、一番書くのが重い。** 3本目として書くのが正解。最初から自己開示の重い記事を出すと離脱する読者も多い。

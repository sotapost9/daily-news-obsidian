# キャリア・評価シート向け分析資料 (2026-02-19)

上司への評価シート記入依頼・自己評価に向けた、Mid-Long Term（5年後など）の「To-Be（あるべき姿）」と「As-Is（現状）」の整理です。

---

## 1. 目指す人材像・キャリア (Ideal Self/Career)

### To-Be (中長期：5年後〜)
**「日本一のEmpathic Designer / 社会課題解決を実装するπ型人材」**
*   **コア・アイデンティティ**: デザイナーと異分野（ビジネス、エンジニアリング、福祉、哲学など）の間に立ち、翻訳者として機能する「π（パイ）型人材」。
*   **専門性**: サービスデザイン × デザインリサーチ（特にインクルーシブリサーチ・当事者研究）。
*   **ありたい姿**:
    *   「効率とエンパシー」「資本主義と倫理」のような二項対立を乗り越える「闘争するサービスデザイン」の実践者。
    *   センシティブなテーマ（メンタルヘルス、貧困、死生観など）において、当事者に深く寄り添いながらビジネスとして成立させる社会起業家・デザイナー。
    *   社内外で「Empathyといえば山中」と想起される存在（社内最高倫理責任者のような立ち位置）。

### As-Is (現在：2026年初頭)
**「情熱と行動力はあるが、足腰（ロジック・型）の強化が必要なフェーズ」**
*   **ポジション**: アナリスト（シニアアナリストへの昇格を目指す段階）。
*   **強み**:
    *   高い熱量とコミットメント（「プライドが高い」と評されるほどの意思）。
    *   建築・空間設計などのバックグラウンドを活かした独自の視点。
    *   UnD（Universal Design）やI&Dコミュニティへの自発的な貢献とリーダーシップ。
*   **課題**:
    *   「やりたいこと」への思いが先行し、組織として必要な「泥臭い仕事」や「型」への適応が発展途上。
    *   クライアントやMDと対等に渡り合うための「ロジカルシンキング」「共通言語」の不足。

## 2. 経験していきたいこと (Experience)

### To-Be (中長期)
**「異なる領域を横断し、社会的に重い課題（Pain）を解決する経験」**
*   **領域**:
    *   病院経営の改革、企業のメンタルヘルス改革、就労支援のUX改革など、医療・福祉・ヘルスケア領域。
    *   当事者（マイノリティ、患者）参画型の共創プロジェクト。
*   **役割**:
    *   プロジェクト全体をリードするPM/デザインリード。
    *   異なる職能（エンジニア、ビジネスサイド）を繋ぐ「翻訳者」としてのハブ役。
*   **コミュニティ・発信**:
    *   UnDなどのコミュニティ主催を通じた「場づくり」の経験。
    *   「Empathic Design」の第一人者としての登壇・執筆・ラジオ発信。

### As-Is (現在)
**「PJリーダーとしての『型』を習得し、守備範囲を広げている段階」**
*   **実績**:
    *   Pokemon PJでのWS設計・ファシリテーション・進行リード（評価：Good）。
    *   WEINS PJでの建築知見を活かした信頼獲得。
    *   Obsidian勉強会などの自主的なナレッジシェア。
*   **直近の経験目標**:
    *   「ミニマネージャー」として、特定のタスク領域（リサーチ、WSなど）を完結してリードする経験。
    *   メンタルヘルス・マネジメント検定（II種/I種）の取得を通じた、専門領域の知識獲得。

## 3. 身につけたいケイパビリティ (Capabilities)

### To-Be (中長期)
**「AIに代替されない人間力 × 異分野をつなぐ翻訳言語（スキル）」**
*   **Human Skills (AI代替不可)**:
    *   **倫理的判断力 (Ethics)**: 「何をすべきでないか」を判断する羅針盤。
    *   **深い共感力 (Empathy)**: N1の痛みを想像し、憑依する力。
    *   **責任を負う力**: 決断し、結果を引き受ける覚悟。
*   **Hard Skills (翻訳言語)**:
    *   **インクルーシブリサーチ**: センシティブな対象者へのインタビュー・観察技術。
    *   **ビジネスデザイン**: 課題を「お金に変える（事業化する）」ロジックと戦略眼。
    *   **ストーリーテリング**: 複雑な事象を感情に訴えかける物語に変換する力。

### As-Is (現在)
**「独自の『感性』をクライアントに届けるための『論理』の習得」**
*   **習得中/課題**:
    *   **ロジカルシンキング**: 2026年の最重要テーマ。クライアントフェーシングに耐えうる論理構成力。
    *   **ドキュメンテーション**: スライド作成、資料作成の「型」とスピード。
    *   **作業の効率化**: クオリティとスピードを両立させるための業務プロセスの型化。
*   **保有**:
    *   デザインへの熱意、建築的思考、Obsidianを活用したナレッジ管理能力。

## 4. 目指す姿に向けたPJ (Projects)

### To-Be (中長期)
**「『闘争するサービスデザイン』を体現する、高難易度かつ社会的意義の高いPJ」**
*   **テーマ**:
    *   メンタルヘルス、障害者支援、貧困、D&Iなど、資本主義の論理だけでは解決しづらいテーマ。
    *   「ケア」と「ビジネス」の両立が求められるPJ。
*   **スタンス**:
    *   単なる受注作業ではなく、クライアントと共に社会課題の根源に向き合うパートナーシップ型のPJ。
    *   「裂け目（組織やサービスの分断）」を埋めるような、統合的なPJ。

### As-Is (現在)
**「ロジックと信頼を積み上げ、『やりたい案件』を引き寄せるための足場固めPJ」**
*   **現状のPJ**:
    *   大手クライアントのサービス改善・構想案件（Pokemon, WEINSなど）を通じ、基礎的なコンサルティングワークと信頼関係構築を学んでいる。
*   **意識すべきこと**:
    *   自分の「やりたいこと（Empathy/社会課題）」を主張するだけでなく、目の前のPJで圧倒的な成果（ロジック・効率・雑務含む）を出し、組織とクライアントからの「信頼貯金」を貯める時期。
    *   今のPJの中で「Empathy」や「倫理」の視点をどう滑り込ませるか、という小さな実験の実践。

## 5. 過去半年間（2025下期〜2026年初頭）の目標達成状況

過去半年間のノートおよび日記の分析から抽出した、各目標に対する主な達成事項・進捗は以下の通りです。

### Community - 社内外のボランティアに月1回以上参加する
*   **「ボランティア」の構造的・サービスデザイン的分析**
    *   単なる参加にとどまらず、書籍『イン・ザ・メガチャーチ』等の知見から、「ボランティア活動を通じて『自分が誰かの役に立った』という心理的安全性と自己有用感を即座に得られる仕組み」をシステム思考で分析。
    *   社会の現場における「生の現場」の体験価値を言語化し、次期（FY26）の具体的なアクションプラン（月1回の参加）への接続を行った。

### Client Value Creation - DR・BDとしての自走
*   **Pokプロジェクト（2025年11月〜2026年1月）における自律的進行**
    *   WS内容のコンセプト設計からワーク、詳細なロジ管理（Excelでの可視化等）に至るまで、マネージャーやSMEの相談の場を活用しながら自律的にリード。
    *   主要な意思決定者の関与が限定的（マネージャーが他PJに7割稼働）な状況でも、PJを予定より前倒しで安定進行させる「自走力」を発揮した。
*   **PRIDE+プロジェクト（2026年1月〜2026年3月）における定性調査の自律的リード**
    *   インタビュー調査において、対象者のセットアップから実査、まとめに至るまでの一連のプロセスを率先して推進。
    *   タスクレベルでの高い自律性と先回りの行動により、チーム全体の負荷を大幅に軽減する「自走力」を発揮した。
*   **一次情報への執念とクライアント要件への柔軟な対応**
    *   週末の実店舗訪問やユーザーへの直接ヒアリングなど「一次情報が全て」という信条のもと、圧倒的なリサーチ量で知識の厚みを作り、クライアントの組織上の制約やIPの特異性を統合・調整した枠組みを提示できた。

### Client Value Creation - サービスデザインの全体像を理解する
*   **「エンパシー」と「サービスデザイン」の統合的理解**
    *   「効率とエンパシー」や「ケアとビジネス」の両立という難しいテーマに対し、ノート執筆や自己対話を通じて「サービスデザインの存在価値（現場のペイン解消など）」を言語化し、全体像の解像度を上げた。
*   **実践を通じた体験設計のフレームワーク化**
    *   Pokプロジェクトにおいて、店舗体験とECのシームレスな体験価値を定義。ゲーミフィケーション2.0の8属性等の理論を応用し、「Pokらしさ」という抽象概念を非線形なアイデアへと昇華させる深いレベルの議論を展開した。

### Client Value Creation - プロフェッショナリズムを確立する
*   **「プロフェッショナルの掟」の体現とマインドセット変容（インプット）**
    *   書籍『プロフェッショナル原論』を通じ、「過程の努力や表面的な見繕いではなく、本質的な問題解決ができているか結果が全て」というプロフェッショナルの掟を内面化。
    *   12冊（『コンサルタント3年目までの必修ビジネススキル』から「実直ワーカー」から「自走ランナー」への脱皮を意識し、「資料のPoC（クライアントにしっくり伝わるか自問自答で実証実験すること）」を取り入れ、成果物の品質をクライアント目線で一段引き上げる習慣を身につけた）
*   **PJを通じたプロフェッショナリズムの実践と他者評価（アウトプット）**
    *   **Pokプロジェクト**: アナリストとしての基礎（詳細なロジ管理、論点ベースの議事メモ作成）を徹底しつつ、それを超える＋αの価値（WS設計・ファシリのリード）を提供したことで、主要な意思決定者の稼働が限られる中でもPJを安定進行させるプロフェッショナリズムを発揮した。
    *   **PRIDE+プロジェクト**: インタビュー調査において、定性調査の一連のプロセス（セットアップから実査、まとめ）を率先して推進し、タスクレベルでの自律性と先回りの行動により「チームの負荷を下げた」との評価（FB）を獲得した。一方で、「タスク設計レベルでの方針立案」を次回（NA）の課題として設定し、さらなる視座の引き上げに努めている。

### AI Enablement - Song Creativeで一番「Obsidian」を使いこなす
*   **Obsidianを用いた高度なナレッジマネジメントの実践**
    *   日々のFleeting Note、Literature Note、PJの振り返りを一元管理し、個別の事象（案件の気付き、読書記録）を有機的に結合させている。
    *   「KAIGI AI」等の生成AIツールとObsidianを円滑に組み合わせ、リサーチの効率化やアイデアの構造化を実現。
*   **社内へのナレッジシェアとコミュニティ貢献**
    *   「Obsidian勉強会」を自主的に企画・開催し、自身の「こだわり」や運用手法を体系化して発信。社内でのAI・ナレッジ管理ツール活用におけるオピニオンリーダーとしての存在感を示した。

### Great Place to Work for Reinventors - 読書会「UnD」をサービスデザインし、累計参加者100人を目指す
*   **「読書会」のサービスデザインとリブランディング**
    *   「UnD」への名称リブランディングを実施。
    *   ジョブ理論（「招待されたい」「敷居が高いと感じる」等のペインとジョブの特定）や、ゲーミフィケーションの知見を組み込み、「理論統合と体験設計の全体像」として読書会自体を一つのサービスとして再設計。
*   **参加障壁を下げるアットホームな場づくりの実践**
    *   「読書会は敷居が高い」という世間の認識に対し、参加者が心理的安全性を得られる体験設計（テンプレート化や運用ルールの整備）を構築し、持続的なコミュニティ成長（累計100人の目標達成）に向けた基盤を確立した。
